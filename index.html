Intelligent matching, 5 dimensions

Our AI scores every potential match across 5 factors for the best possible ride.

🗺️

Route Overlap

Polyline-based route comparison ensures drivers and riders share meaningful path overlap, not just proximity.

⏰

Timing Alignment

Matches riders within a configurable time window — no waiting 45 minutes for a ₹20 saving.

💺

Seating Capacity

Drivers set available seats; the system pools compatible riders for fuller, more economical trips.

💰

Budget Matching

Riders set max fare; drivers set min price. The AI finds the Pareto-optimal price range for both.

Safety Verification

Trust Score combines ID verification, ride history, ratings, and emergency contact status.

Set a weekly schedule once and get auto-matched every day — zero rebooking overhead.
